# Bookshelf conventions

- Display a book only after adding its real published front-cover image locally and recording its source URL. Never use generated front covers or title-only placeholders as substitutes.
- Keep narrow spines on the main shelf; show the real front cover on click. Spine textures may be reconstructed from the real covers, but must never be described as verified physical spine scans.
- Keep the default page visual and simple. The reading journal and editing controls are secondary and collapsed by default.
- Keep purchase/library-added dates separate from listening observations. Never infer start or completion dates from listening history alone.
- Size thickness using the documented page-count estimate and disclose estimates; never describe reference print-edition sizing as the user's exact digital edition.
- Preserve local browser notes and status edits when adding published book metadata. Run npm test before completion.
